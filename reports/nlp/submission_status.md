## Воспроизведение PDF

Документ собирается из `reports/nlp/report.md`, без изменения ML-окружения.
Дополнительная зависимость - reportlab; шрифты DejaVu Sans (обычный и жирный).

```bash
python tools/build_nlp_report_pdf.py --font-dir /path/to/dejavu/fonts
```

Выход: `output/pdf/nlp-report.pdf`. После изменения текста надо пересобрать PDF
и проверить каждую страницу. Проверка доступности окончательной ссылки на тег
фиксируется в задаче №27 после публикации тега. Готовый файл и тег не означают
автоматической отправки в личный кабинет.
