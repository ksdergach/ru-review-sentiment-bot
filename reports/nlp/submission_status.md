## Сборка PDF

Дополнительная зависимость только для документа: `reportlab`; она не нужна для
бота и не добавляется в ML-окружение. Нужны шрифты DejaVu Sans (обычный и жирный).

```bash
python tools/build_nlp_report_pdf.py --font-dir /path/to/dejavu/fonts
```

По умолчанию создаётся `output/pdf/nlp-report.pdf`. Содержимое берётся из
`reports/nlp/report.md`; явные границы страниц сохранены в комментариях Markdown.
Для проверки можно использовать Poppler (`pdftoppm`) и pypdf. При изменении
текста необходимо пересобрать PDF и проверить каждую страницу.

## Проверка доступа без авторизации, 09.10.2026

Репозиторий имеет видимость **PRIVATE** (подтверждено GitHub API).
Анонимные HTTP-запросы без cookies и токенов к корню репозитория и прямой
ссылке на PDF вернули **404**. Поэтому файл нельзя считать открытым для
преподавателя, даже если участники команды видят его через свой аккаунт.
Часть ссылок на страницы исходников вернула 503; их публичный доступ также
не подтверждён. Подавление проверки TLS не использовалось.
