# N03: исправления ревью PR №29, 09.10.2026

- Загрузка и инференс вынесены через `asyncio.to_thread`; команды могут обрабатываться во время инференса.
- Одновременно выполняется один запрос модели; остальные получают сообщение о занятости. При отмене обработчика слот сохраняется до завершения его потока.
- Первая загрузка защищена потоковым lock; параллельные прямые вызовы не загружают комплект повторно.
- Неизвестные команды определяются по Telegram entity `bot_command` с offset=0. Отзывы с начальным `/` без такой entity классифицируются.
- Общие константы классов импортируются из `train_baseline`; `load_bundle` проверяет mapping. Путь берётся из `model_dir` и `bundle_name` конфигурации N03.
- Базовый `InvalidTextError` превращается в сообщение пользователю. Неверный формат токена диагностируется при чтении окружения, без вывода значения токена.
- В README явно запрещено автоматическое обучение при старте и при отсутствии модели.
