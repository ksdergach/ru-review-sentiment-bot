# T09: ручная проверка голосового Telegram-бота

**Статус: проведена 16.11.2026** участником команды на коммите `75c73fe`, через
Telegram, с реальными моделями RuBERT (T06) и Whisper Small. Это ручной smoke-тест
сценариев, а не статистическая оценка качества модели.

Инструкция: [README, раздел T09](../../README.md#голосовой-telegram-бот-t09).
Используется отдельная отладочная запись; 36 финальных записей T11 не используются.
В протокол не вносить токен, имя/ID пользователя или бота, аудио и полный текст отзыва.

## Локальная проверка с реальными моделями без Telegram (15.11.2026)

Подтверждает загрузку моделей при старте и отрицательные сценарии, но **не заменяет**
живой Telegram-сценарий: настоящей голосовой записи с речью и токена не было.

Окружение: Linux, Python 3.12.3 (в проекте зафиксирован 3.13.7), пакеты по
`requirements.txt`, torch CPU. RuBERT получен `python tools/fetch_transformer.py`
(7 файлов совпали с `reports/transformer/run_metadata.json`), Whisper — по
`configs/speech.json`. Принятого комплекта baseline в окружении не было.

| Проверка | Результат |
|---|---|
| `python -m src.bot` без `TELEGRAM_BOT_TOKEN` | код 1, `Startup failed: Environment variable TELEGRAM_BOT_TOKEN is not set` |
| Backend baseline без комплекта | код 1, `Classifier bundle is unavailable (FileNotFoundError: baseline bundle file not found)` |
| Недопустимый `CLASSIFIER_BACKEND` | код 1, `ValueError: CLASSIFIER_BACKEND must be baseline or rubert`, значение не выведено |
| Старт с RuBERT и Whisper | обе модели загружены до polling за 9,9 с; при следующих запросах переиспользованы |
| Голос: 3 с тишины (WAV) через `voice_handler` | сообщение о нераспознанной речи, без метки; временный каталог удалён |
| Голос: повреждённый файл | `decode_failed`, безопасное сообщение без метки; временный каталог удалён |
| Голос 31 с по метаданным | отказ до скачивания |
| Текстовый режим, искусственная фраза | `Тональность: положительная (positive)` |

Скачивание заменено копированием локального файла; Telegram API не вызывался.
