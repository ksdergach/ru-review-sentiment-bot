## 1. Проверяющий, окружение и основания

Проверяющий — участник команды на собственном Mac, пользователь проекта.
Команды подготовки и автоматических проверок выполнял агент по пошаговому
согласованию с пользователем. Пользователь лично вводил токен в своём терминале,
запускал бота, отправлял сообщения через Telegram и передавал снимки результатов
в диалоге. Установка не выдаётся за выполненную человеком без помощи агента.

Созданы отдельный Git clone и новое `.venv`; готовые библиотеки, модели и кэш
автора предварительной Linux-проверки не копировались. Использован уже установленный
интерпретатор Python; до установки зависимостей в новом `.venv` был только `pip 25.2`.
Существующие рабочие копии проекта с локальными изменениями сохранены.

Её SHA-256 также не совпал побайтово ни с одним из 36 хешей опубликованного состава T11;

Принятые модели не переобучались; код и конфигурации не изменялись.

## 2. Установка и проверка окружения

Ниже приведены выполненные команды; все команды после `cd` запускались из корня
новой копии. Для установки интерпретатор указан явно, поскольку `python3.13`
не находился в PATH. Новый Python устанавливать не потребовалось.

```bash
git clone --branch vds2/s20261118-173423-2ad78b --single-branch https://github.com/ksdergach/ru-review-sentiment-bot.git ru-review-sentiment-bot-t16
cd ru-review-sentiment-bot-t16

/opt/anaconda3/envs/nlp-py3137/bin/python -m venv .venv
.venv/bin/python -m pip --disable-pip-version-check --no-cache-dir install -r requirements.txt
.venv/bin/python -m pip --disable-pip-version-check check
.venv/bin/python tools/check_environment.py
```

совпали, импорты пакетов и классов BERT, Whisper и aiogram успешны.

## 5. Ручные сценарии через Telegram

Пользователь запускал `.venv/bin/python -m src.bot` с `CLASSIFIER_BACKEND=rubert`.
Токен вводился скрыто через `getpass` и передавался только в окружение процесса.
Перед запуском пользователь подтвердил отсутствие другого работающего экземпляра
этого бота. HTTP-сессия приложения и настройки прокси в коде не изменялись.
Сообщения отправлялись пользователем через Telegram; снимки ответов просмотрены
в диалоге и не публикуются в репозитории.

| Сценарий | Наблюдение | Итог |
|---|---|---|
| S1. Запуск | Бот ответил на `/start`, показал назначение и ограничения | PASS |
| S2. Голосовой киноотзыв | Получены расшифровки и тональность: положительный пример — `positive`, 96,8%; отрицательный — `negative`, 94,8% | PASS |
| S3. Обычные текстовые киноотзывы | Положительный — `positive`, 97,2%; отрицательный — `negative`, 97,0%; нейтральный — `neutral`, 82,0% | PASS |
| S3. Точная расшифровка отправлена текстом | Для двух киноотзывов метки и показанные проценты совпали: `positive`, 96,8%; `negative`, 94,8% | PASS |
| S4a. Текст длиннее 2000 символов | Ответ: «Сообщение слишком длинное. Максимум — 2000 символов.» | PASS |

Дополнительно бытовое сообщение вне кинотематики получило `neutral`, 72,6%
и голосом, и при отправке расшифровки текстом. Это наблюдение о работе цепочки

Точное число символов полученного ботом длинного текста отдельно не измерялось;
пользователь отправил подготовленный блок длиннее лимита, отказ виден на снимке.
Длительность отрицательного голосового и голосового для S5 видна как 3 с.
Длительность положительного голосового в предоставленном фрагменте снимка не видна.
Дословная точность ASR и WER этим протоколом не устанавливаются.
Ручные проверки `/help` во время обработки, таймаута 60 с, лимита 5 МиБ,
повреждённого аудио и удаления временных файлов отдельно не подтверждены в диалоге;
соответствующие автоматические проверки входят в полный прогон.

## 6. Возникшие проблемы и отклонения от инструкции

| Случай | Что установлено и что сделано |
|---|---|
| P2: тесты на проверенном commit стоят до установки RuBERT | В этой проверке полный `pytest` выполнен после получения моделей. После проверки чек-лист исправлен локально: итоговый запуск перенесён после установки моделей, тесты принятого RuBERT должны выполниться без пропуска. Замечание опубликовано в PR; публикация исправления ожидается |
| Сетевые ограничения среды агента | Первые clone, установка пакетов и получение моделей не прошли в ограниченной среде; согласованные повторы с сетевым доступом успешны. Первый запуск Whisper вернул `model_load_failed`, повтор — `ok` |
| Первый запуск Telegram: HTTP 404 на `getMe` | Причина по доступным данным не установлена. После повторного скрытого ввода токена отдельная проверка вернула `GETME_OK` и подтвердила нужного бота; последующий запуск и ручные сценарии успешны |
| После голосового не было ответа | Проверка не обнаружила процесс `python -m src.bot`; пользователь подтвердил, что закрыл терминал. После повторного запуска с открытым терминалом голосовые обработались |
| R1 из предварительного протокола: прокси | Изменение HTTP-сессии не потребовалось на этом Mac. Маршрут сети и наличие системного VPN/прокси отдельно не исследовались; работоспособность в других сетях с обязательным прокси не подтверждена |
| R2: принятый baseline отсутствует | Проверка выполнена с RuBERT; причина пропуска baseline отражена выше |

Замечание P2: [комментарий ревью](https://github.com/ksdergach/ru-review-sentiment-bot/pull/42#issuecomment-6988352784).

Команды `check_environment.py` и `verify_transformer.py` выполнены штатно.
Из вспомогательных действий использовались безопасный ввод токена, отдельный
