
проверку сохранённого результата связываем с указанным SHA-256.

## Фактический прогон

Модель предварительно скачана в игнорируемый кэш. Проверочная команда:

```bash
HF_HUB_OFFLINE=1 python tools/verify_speech.py --audio artifacts/speech/teacher_debug.ogg --confirm-debug-audio
```

Финальный замер сделан после завершения общего набора тестов, без его
параллельного запуска. Время включает декодирование и полный проход генератора;
первый вызов также включает загрузку модели. Скачивание весов в замер не входит.

| Сценарий | Статус | Полное время, s | Загрузка модели, s | Результат |
|---|---|---:|---:|---|
| 12 s речи, первый вызов | `ok` | 61.744 | 2.637 | 2 сегмента, 162 символа русского текста |
| Та же речь, та же модель | `ok` | 60.080 | 0 | Тот же полный текст |
| 3 s сгенерированной тишины WAV | `empty` | 0.105 | 0 | Пустой текст, без технической ошибки |
| Повреждённый OGG | `error` | 0.001 | 0 | `decode_failed`, без частичного текста |

Объект модели остался тем же при повторном вызове. Тексты сохраняются только
в локальном `artifacts/speech/transcripts.json`. SHA-256 одинаковых транскрипций:
`0f7290d95a9b0ea50f0be74c5e57d5396a3cb905dece397a8f92fab749525a17`.

**Ограничение скорости:** на этом Mac выбранный профиль обрабатывает 12 s речи
примерно за 60 s (RTF около 5). Это подтверждение работоспособности, но такой
профиль требует настройки скорости перед демонстрацией на Mac. Замеры T05
на Windows и этом Mac нельзя считать взаимозаменяемыми. Лимиты, занятость и
жёсткий таймаут реализуются отдельно в T10.

Фиксированный язык ru не является автоматическим определением языка.
По этому фрагменту не считался WER и не оценивалась тональность. Набор отладочных
проверок не доказывает качество на шумной речи или произвольных сообщениях.

- Git blob всех трёх исходных Parquet совпал с HEAD.

Тест с ленивым генератором проверяет чтение каждого сегмента в рабочем потоке,
полный текст и однократную загрузку. Проверены ошибка после первого сегмента,
пустые сегменты, повреждённый файл, реальные декодирование/resampling WAV,
параллельные вызовы, восстановление после ошибки загрузки и повторная отмена.
При отмене файл остаётся жив до окончания рабочего потока и затем может быть
удалён вызывающим кодом. Такой контракт не является жёстким таймаутом.

ONNX Runtime выдал предупреждение о сохранении идентификатора телеметрии в
ограниченном окружении; распознавание и проверки завершились успешно.
Для тестов, использующих Git, выбран рабочий Git в PATH вместо системного Apple Git.
