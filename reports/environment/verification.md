## Пути и защита артефактов

Проверены 26 путей командой `git check-ignore --no-index -q <путь>`:
16 локальных путей исключены, 10 путей исходников/конфигов/отчётов не исключены.
Полный список результатов и SHA-256 исходных файлов: [git_safety.json](git_safety.json).

Примеры проверок для воспроизведения:

```bash
git check-ignore -v .env .env.local artifacts/audio/debug.wav models/baseline/model.joblib checkpoints/run/model.safetensors .cache/huggingface/tokenizer.json data/processed/train.parquet
git check-ignore --no-index NLP_dataset/train-00000-of-00001.parquet .env.example configs/data_prep.json reports/environment/verification.md
```

Первая команда выводит правила исключения. Вторая не выводит ничего и возвращает
код 1: эти файлы должны оставаться доступными для Git.
Все три Parquet дополнительно проверены сравнением Git blob с HEAD:
байты исходного датасета не изменены.

Пути этапов сохранены в `configs/data_prep.json`, `configs/baseline.json`
и `configs/resource_check.json`. Они относительные и описаны в корневом README.
Секреты и абсолютные пути конкретной машины в конфиги не добавлялись.
