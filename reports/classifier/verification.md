# T07: проверка общего интерфейса

Реализованы baseline и RuBERT через `src.classifier.predict` и фабрику
`create_classifier`. Обязательный результат: label, label_id, confidence,
probabilities в порядке negative/neutral/positive. Поле truncated сообщает об
усечении; baseline возвращает false. Пустые, нестроковые и превышающие 2000
символов сообщения отклоняются до загрузки модели.

## Выполнено

- Полный набор: `HF_HUB_OFFLINE=1 .venv/bin/python -m pytest -q` — 529 passed.
- Контракт проверяет конечность, диапазон и сумму вероятностей, соответствие
  label/label_id и максимальной вероятности.
- Локальный BERT с настоящими сохранёнными весами и tokenizer используется
  в тестах без скачивания: загрузка один раз при конкурентных вызовах,
  совпадение с обработкой T06, граница max_length с учётом специальных токенов,
  отображение усечения, отказ при несовместимых и изменённых файлах.
- Для обоих backend результат общего вызова совпадает с адаптером бота и
  `tools/predict_text.py`; для RuBERT также с `train_transformer.predict_texts`.
- Настоящий локальный baseline `models/baseline/tfidf_logreg_baseline.joblib`
  проверен на трёх контрольных текстах `train_baseline._smoke_texts()`:
  positive / negative / neutral. Метки и вероятности совпали с прямым вызовом
  сохранённой модели; ответ бота совпал с форматированием общего результата.
  Train-ID SHA-256: `7736eac8949e4010fc2d80060c980d7e7476ee0f23178f68e99b8226e38e5bbf`.
