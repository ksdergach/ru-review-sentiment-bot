конфигурации `pc`, ревизия `526df6aa3fdfc99cdbb2e2ce79406ae67816c1f9`.
Повторная проверка API выполнена самим скриптом, без скачивания текстов.
Схема, размеры сплитов и распределения совпали с планом: 100 502 строки,
из них 96 749 русскоязычных. Пересечения фильмов между сплитами — ноль.

Тесты проверяют отказ при подмене байтов/удалённого SHA-256, недопустимых метках,
языках и пустых полях, расхождение с планом, выборку только из русского train,
экранирование текста HTML и сохранность записанных человеком заметок.

SHA-256 повторно созданных метаданных:

- `audit.json`: `e20af4d7e1d676711e47aa723c8779fa577a6b643e59ab5f3182c4a8df628977`.
- `sample_ids.json`: `1e29a46bf4a4e6c0fe7a1a1e9291e03267e17fe2b80bfaf763d1647a221e41a4`.

Использовано окружение T01: Python 3.13.7 / macOS arm64. Первый HTTPS-запуск
без системного CA завершился ошибкой локальной конфигурации сертификатов;
повтор выше прошёл с проверкой TLS. В sandbox PyArrow также выдал предупреждения
о недоступности `sysctlbyname`; чтение файлов и все проверки завершились успешно.

Полный набор прежних тестов T03/T04/T05 заново не запускался: их код и конфиги
не изменены. Обучение и оценка моделей на test не выполнялись.
