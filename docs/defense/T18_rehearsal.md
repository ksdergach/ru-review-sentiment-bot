# T18: протокол репетиции защиты

**Статус: репетиция не проводилась.** Это шаблон. Критерий «Репетиция действительно проведена,
роли и результаты записаны» закрывается только после реальной репетиции участниками
и заполнения всех полей ниже. Заполненный шаблон без проведённой репетиции не считается результатом.

Роли не назначены: распределение выбирает команда. В протокол не вносить токены, личные
контакты, аудио и тексты демонстрационных отзывов; участников можно указывать так,
как команда указывает их в отчётах.

## 2. Распределение выступления

Слайды — по [презентации](T18_presentation.pptx), тезисы — в [сценарии](T18_speaker_notes.md).
Ориентировочное время рассчитано на ~15 минут основных слайдов и ~3 минуты показа.

| Часть | Слайды | Ориент. время | Выступающий | Фактическое время |
|---|---|---|---|---|
| Тема, задача, архитектура | 1–3 | 2,5 мин | | |
| Данные и модели | 4–5 | 2,5 мин | | |
| Текстовые результаты T13 | 6–7 | 2,5 мин | | |
| Голос T14 и ошибки T15 | 8–10 | 3,5 мин | | |
| Бот и живой показ | 11 + показ | 4 мин | | |
| Критерии, выводы, ограничения | 12–14 | 3 мин | | |
| Ответы на вопросы | резерв 15–16 | — | | |

Последовательность переключения: _записать, кто передаёт слово кому и кто управляет слайдами
и Telegram во время показа_.
