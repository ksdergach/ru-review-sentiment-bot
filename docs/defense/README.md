## Как пересобрать и проверить презентацию

Слайды собирает [tools/build_defense_deck.py](../../tools/build_defense_deck.py) из опубликованных JSON
T03, T13, T14 и T15. Значения вручную не набираются. Нужен только `python-pptx`: в `requirements.txt`
он не входит, так как боту и оценкам не нужен.

```bash
python -m pip install python-pptx==1.0.2
python tools/build_defense_deck.py            # перезаписывает docs/defense/T18_presentation.pptx
python -m pytest -q tests/test_defense_presentation.py
```

Тест читает `.pptx` как ZIP, без python-pptx. Он проверяет 16 непустых слайдов в формате 16:9
и наличие ключевых метрик T13/T14/T15 из исходных JSON. Кроме того, каждое дробное и многоразрядное
число на слайдах и в подписях графиков должно встречаться в итоговом отчёте или README.

Регламент защиты (длительность, число слайдов) в материалах проекта не найден. В ЛМС указана
только дата защит — 19.12.2026 ([ASSIGNMENTS.md](../course/netology/ASSIGNMENTS.md)).
